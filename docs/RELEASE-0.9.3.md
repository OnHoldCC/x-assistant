依据：[X Original Content Rewards](https://help.x.com/en/using-x/original-content-rewards)，2026-10-28核对。官方说明的合格曝光涉及 Premium 用户、Home Timeline、可见比例和去重，不能用 Analytics 总曝光直接冒充合格曝光；说明未提供固定结算单价。

收益校准保存在当前账号的本地 Rust 后台，可随资料导出，不自动加入外部模型输入。验证覆盖顶部悬停/达标、375px布局、曲线切换、金额公式、缺失值/币种口径、历史日期完整性和账号隔离。
