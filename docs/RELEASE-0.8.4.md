# OnHold 桌面端 0.8.4

更新日期：2026-10-22。

配套 X 助手 1.3.4。沿用 OnHold UI 黑白主题，保留既有数据库、账号和模型资源。

- 在「官方分析」直接发起采集。Rust 排队，CDP 助手在后台打开本人 X 分析页，保存 X 所示周期、来源和采集时间，再关闭该临时页面。
- 无权访问分析页或未出现有效指标时显示失败原因，不把空数据当成零或报采集成功。
- 区分账号帖子采集与官方分析采集，重试保留类型。服务端校验动作、账号归属、登录状态及助手能力，没有任意 URL/脚本执行入口。
- 旧助手继续支持普通采集；更新后才能领取官方分析任务，避免旧版把分析任务误当作普通采集。
- 重绑同一 X 标签页时，延迟到达的旧断开事件不会清掉新连接。
- 首次引导断线后回到连接步骤；宿主读取失败可重试。复制目录不会阻塞扩展管理页的打开。刷新不会解锁尚未提交完成的采集操作，切换账号后仍刷新当前账号。
- Windows 查找 Chrome/Edge 打开连接和安装入口，不交给不兼容的默认浏览器；Edge 使用自身的扩展管理地址。

验证入口：`npm test`、Rust 后台/宿主测试、`test/desktop-browser.mjs`、`test/admin-browser.mjs`。桌面 IPC 的浏览器替身检查安装、启动失败恢复、断线恢复、分析任务和账号切换；集成测试使用临时数据库与隔离 Chromium，执行实际 Rust/WS/CDP 链路。测试数据不写入用户账号，也不发布内容。

Mac arm64 包包含已校验的 Hy-MT2、Laya 和离线运行资源。统计后台不依赖模型加载；这次未新增本机推理服务的自动启动。Windows 平台分支已修正，仍需 Windows 实机安装验证。临时签名包未经过 Apple 公证，不承诺免系统拦截。自动发布、自动评论与移动安装包不在此次桌面功能范围内。
