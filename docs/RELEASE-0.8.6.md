# OnHold 0.8.6 / X 助手 1.3.5

更新日期：2026-10-23。

- 手动采集统一为「立即采集」，移除常驻「刷新数据」和任务页的「新建采集任务」。采集排队/执行期间禁用重复提交，状态每 2 秒刷新；定时计划的「运行中」改为「已启用」，与具体任务状态区分。
- 趋势图显示单个零值、正值或负值的数据点，缺失日期保留为空。仅有首次采集时说明等待下一次比较，完全未读到该指标时说明尚未采到；近似值保留标记。
- 插件概览显示粉丝、关注、浏览、点赞、评论和转发六项真实指标。菜单与手动配对分开，常规概览控制在 Chrome 弹窗高度内；手动配对展开时再显示配置字段。
- 兼容 X 个人主页使用 verified_followers 路径展示总粉丝数的情况，不把明确标注的认证粉丝数当成总粉丝数。
- 修复独立插件设置页无法识别已绑定账号、以及缺少活动页 URL 时抛错的问题。优先使用已绑定 X 标签页的只读 CDP 账号信息。
- 桌面导航使用既有 OnHold 大尺寸菜单项，增加项目间距；插件设置页菜单采用 48px 点击高度。

验证：`test/trend-browser.mjs` 覆盖缺失/首次比较/单点零值/正负值/断点/近似值；`test/admin-browser.mjs` 走实际 Rust/WS/CDP 并检查粉丝链接变体、独立设置页与趋势；桌面、插件和规范页检查响应布局及文字放大。预览截图采用隔离示例数据。

历史缺失数据不会补零或编造曲线。需要重启桌面端、重载新版插件后生效；更改未新增浏览器权限。Mac 包保持内置模型与临时签名，Windows 安装仍待实机验证。
