# OnHold 移动端与 CDP 助手

2026-10-28 · OnHold 0.9 / UI 1.0 · React + TypeScript / Rust / Tauri

## 运营依据

按 Marketing Skills 的 [social](https://github.com/coreyhaines31/marketingskills/blob/main/skills/social/SKILL.md)、[analytics](https://github.com/coreyhaines31/marketingskills/blob/main/skills/analytics/SKILL.md) 和 [onboarding](https://github.com/coreyhaines31/marketingskills/blob/main/skills/onboarding/SKILL.md) 重构：围绕触达、讨论和数据可用性做决策；以真实账号连接和数据入库作为首次激活；保留数据缺失、近似、来源与观测时间。未接入额外第三方埋点服务。

## 手机操作

| 入口 | 功能 | 用途与口径 |
| --- | --- | --- |
| 概览 | 粉丝、已采集浏览/评论、可比帖评论率、趋势、重点帖子 | 今日/7 天/30 天控制观测净增；卡片累计值仍明确标为已采集数据。官方分析独立保留原周期 |
| 内容 | 帖子/话题卡片、内容搜索、最新/浏览/评论/评论率排序、详情与原帖评论入口 | 覆盖已采集内容，不以所选观测周期冒充发帖时间筛选；缺失排在已知数据之后 |
| 账号 | 切换账号、查看登录与在线状态、最近采集、手动采集 | 账号切换清空旧视图，数据不跨账号合并 |
| 收藏 | 帖子、标签、搜索与详情 | 保存到 OnHold 当前账号，独立于 X 收藏状态 |
| 自动化 | 默认暂停的定时回关/取消关注计划、手动恢复 | 限制后停止；运行依赖电脑上在线插件 |
| 日志 | 实时事件、筛选与暂停 | 与桌面共用 Rust 事件记录 |

连接与工作空间从右上角状态灯打开。采集记录保留为内部任务视图，主导航不重复显示采集操作。

小于 768px 使用五项底部导航和卡片列表；平板及桌面保留侧栏与数据表格。底部导航、详情和顶栏处理系统安全区；触屏操作至少 44px；设置与控件支持文字放大。

手机原生端先通过宿主识别平台。未配对时不请求空的本机数据库；后台验证成功后才保存远程配置。连接失败保留当前工作空间，不替换已保存配置。远程模式不会读取后台配对密钥或调用电脑插件安装命令。

原帖链接继续由 Rust 严格校验 X 域名与帖子路径。手机通过 [Tauri 官方 Opener](https://v2.tauri.app/plugin/opener/) 打开系统浏览器，电脑沿用现有浏览器入口。

## CDP 插件 1.4.0

- 连接、登录正常：显示真实账号、Rust 中的粉丝/关注/浏览/点赞/评论/转发、已采集帖子数、最近采集与任务结果；优先展示官方7天数据与创作者进度；主操作为「立即采集」。
- 未配对：打开电脑工作台完成配对；地址和密钥折叠到手动配对中。
- 已配对但离线：重新连接 X 标签页；重新连接优先选择最近使用的 X 页面，不要求弹窗本身处于 X 标签页。
- 退出登录或账号切换：显示状态并提供重新绑定；不提供可执行的采集按钮。
- 后台不可用或密钥失效：显示真实错误；按绑定账号保留最后成功的摘要，明确标为离线快照与更新时间；修改后台地址或密钥时清除缓存。
- 地址草稿不被轮询覆盖；密钥保持密码输入，不进入摘要消息、URL 或后台展示。
- 翻译、广告设置与弹窗共用 OnHold 颜色与系统字体。保留广告延迟淡出、关闭时恢复，以及现有 X 帖子/评论操作。

新增 `CDP_OVERVIEW` 仅允许插件自身页面调用，固定查询绑定账号的 dashboard/jobs，返回白名单摘要，不暴露帖子正文、配对密钥或任意后台操作。既有回环地址校验、WS 认证与 Origin 限制保留。

评论率、加权参考值只在分子分母来自同次有效观测时计算。无浏览、无可比时间或缺失输入显示「—」；真实零显示 0；近似数保留「≈」。加权参考值仍独立于 X 官方互动率，不用作推荐概率。

## 验证与交付范围

`npm run app:build`、`npm test`、`test/mobile-browser.mjs`、`test/admin-browser.mjs`、`test/ui-browser.mjs`。浏览器测试覆盖手机首次连接与失败恢复、任务账号隔离/重试/筛选、内容排序与评论入口、375–812px、200% 文字，以及实际 Rust + CDP + WS 采集链路。截图位于 `app/screenshots/mobile-*.png` 和 `plugin-*.png`，使用隔离测试数据，不代表用户账号表现。

手机首次连接与远程模式通过原生 IPC 的浏览器替身验证；Android/iOS 真机与安装包仍需平台 SDK、签名及可访问的 HTTPS 后台。源码改动不会自动更新已经打开的桌面应用或已加载的浏览器扩展；插件需安装或重载新版。当前没有自动发布内容或无人值守评论操作。
