# X 运营指标口径

核对日期：2026-10-27。数据留在本机。模型不参与财务和运营指标的算术计算。

## 数据来源与周期

账号概览来自 https://x.com/i/account_analytics ，每份快照记录账号、读取时间、页面周期与认证过滤状态。读取当前 Analytics 页面优先使用该页的数据，不用缓存冒充最新数据。奖励门槛来自当前账号的 Original Content Rewards 资格页，目标与时间窗口直接解析，不固定写死为某个历史版本。

7D、4W、90D 与30天不能互换；不能把重叠窗口相加。缩写计数保留约数标记，缺失数据不按零处理。总曝光、认证主页曝光、合格去重曝光各有不同口径，不相互代替。

## 指标

- 官方互动率：直接显示 X Analytics 的 engagement rate；该指标的互动包含点击等赞评转以外的行为。
- 曝光到主页访问：同周期 profile visits / impressions ×100%，为访问事件比率，不是独立用户转化概率。
- 每千曝光互动：同周期 engagements / impressions ×1000。
- 每千曝光主页访问：同周期 profile visits / impressions ×1000。
- 加权互动率（自定义参考）：(0.66×点赞+5×评论+转发)/曝光×100%。系数借用公开排序默认参数，将其用于已观察计数属于本产品参考口径，不等于 X 推荐算法输出或官方互动率。
- 关注转化率：只有同周期新增关注数据时才可计算；总粉丝数不能作为新增关注的替代。

## 创收与收益

未达标账号的主数字 = min(认证粉丝/当前粉丝门槛,认证主页曝光/当前曝光门槛,1)×100%。这是两个数值门槛的进度，不表示其他资格均满足。数值达到目标或页面明确可开通/已开通后隐藏进度，保留实际开通状态。

未达标且未开通时，大号显示“可获收益 ¥0”与“未开通”标签，含义为维持当前状态下的预估，不是历史到账。

已达标账号的30天情景收益 = 本人近30天合格曝光 /1000 × 本人校准的每千合格曝光收益（元）。缺少任一依据时不编造金额，显示暂无法估算。估算参数按账号隔离，手动校准项标明来源和保存时间。公开计算器的受众比例、地区系数及RPM范围不作为官方参数。

X 当前说明合格曝光来自 Premium 用户的主页去重曝光，含可见面积条件；排除付费、人工或欺诈曝光。资格页90天进度不能直接当30天可计费曝光。
