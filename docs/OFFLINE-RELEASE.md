# OnHold 助手离线包

完整包包含浏览器扩展、Skill、独立 Node.js、Python、llama.cpp、Hy-MT2 翻译模型、Laya 评分模型和依赖。无需用户手动安装模型运行环境。

## 下载与安装

1. 按电脑选择 `darwin-arm64`（Apple 芯片 Mac，macOS 14+）或 `win32-x64`（常见 Intel / AMD Windows 10+）。
2. 下载该平台的全部 `.tar.gz.partNNN` 分卷和对应 `-install.command` / `-install.ps1`，放进同一文件夹。
3. 将这个文件夹交给 Agent，告诉它“使用此离线包安装 OnHold 助手”。也可以在 Mac 用 Bash 执行 `.command`，在 Windows 用 PowerShell 执行 `.ps1`。安装入口会先校验所有分卷，再自动解压和部署。
4. 按浏览器正常流程加载安装器输出的扩展目录。首次加载仍需要浏览器确认。

不要混用不同版本或不同平台的分卷。系统策略阻止脚本时应按提示处理，不建议关闭系统安全策略。

建议预留 16 GiB 可用磁盘空间，安装期间需要同时保存分卷、临时解压文件和最终模型。

## 验证范围

发布流水线在对应系统完成联网准备、生成离线包、隐藏系统 Node、阻断外网代理后安装、真实翻译与标签分析、重启复用 SQLite、卸载检查。两个平台全部通过后才公开 Release。

Windows 构建环境没有可用于推理的实体 GPU；GPU 后端仍需在用户电脑上检测兼容性。模型支持的语言和翻译质量受模型本身限制。

Windows 标准离线包包含 Vulkan 翻译运行时及 CPU 版 PyTorch 评分依赖：翻译可按本机兼容性使用显卡，Laya 评分使用 CPU。需要 CUDA / Intel XPU 版评分依赖时，应在对应 GPU 环境重新构建离线包，不能用 CPU 包宣称支持全部显卡。

## 数据与许可证

包中不含用户数据库、浏览器设置、API 密钥或服务控制令牌。卸载默认保留本机数据及备份。

助手代码采用仓库中的定制源码可用许可证；模型及第三方依赖遵循各自许可证，包内附许可说明。
