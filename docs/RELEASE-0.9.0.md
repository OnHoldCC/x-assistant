# OnHold 0.9.0 / CDP 1.4.0

更新日期：2026-10-25。

本版围绕 X 创作者日常运营：官方账号曲线、资格进度、素材收藏和可追踪的复盘。界面继续使用 OnHold 的黑灰蓝主题与组件。

- 官方分析从原生 CSV 读取逐日记录，周期跟随 X 提供的选项；日/周/月汇总，多指标同图或单项原值曲线。定时采集刷新7天，手动采集刷新全部可用周期。
- 创作者认证粉丝与认证主页曝光进度；收益使用本人填写的合格曝光和历史单价估算，缺少依据时不生成金额。
- X 帖子详情可保存 OnHold 收藏并添加标签，后台提供搜索、标签筛选与编辑。
- 本地运营记忆、复盘与采用记录；本机 Codex CLI 或兼容 API，发送前预览，API Key 存系统凭据库。
- 自动化支持定时回关与取消关注，新计划默认暂停；遇到限制或不确定结果停止，需要手动恢复。默认取消范围只包含本工具关注且到期未回关的账号。
- 全局费用政策扫光 GIF；连接设置合并为右上角状态灯与抽屉，限制时全局提示；作者页三行链接和折叠版本记录；实时系统日志。
- 插件离线保留带时间标记的摘要，简化操作；Mac 图标使用无透明外边距的 ICNS。

安装包仍附带固定的离线模型和运行环境。统计后台独立运行；旧本机翻译模型服务的自动启动未在本版新增。

验证：Node测试56项通过（Windows专属1项跳过）；Rust后台7项通过；Mac宿主和模型适配5项通过；隔离浏览器验证WebSocket、官方CSV、异步周期切换、定时采集、失败保留、账号隔离与关注限制停止，以及界面与移动布局。

范围：Mac Apple Silicon 构建；Windows源码与CI配置保留，未提供本次Windows实机安装验证。Android/iOS未生成安装包。真实账号关注/取消关注未执行，真实模型调用需用户配置。Mac为临时签名，未做Apple公证，不能保证其他设备没有系统提示。
