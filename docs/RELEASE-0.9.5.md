# OnHold 0.9.5 / X 助手 1.5.17

更新日期：2026-10-30。

## 热点取材与逐条发文

- 后台直接读取 60s 微博、小红书热榜及 BBC 娱乐、Guardian 文化 RSS。60s 是第三方聚合接口，榜单线索仍须核实。
- 每批热点保存到 SQLite。每个发文周期只取一条，交给 Codex 联网核实并生成正文，校验通过后由浏览器插件发送；本批处理完后才拉取下一批。重复、无法核实和过期的内容跳过。
- 模型只接收当前候选，RSS 摘要移除 HTML 并限制长度，减少每次重复提交整批材料。用量记录区分输入、缓存输入与输出，不把缓存重复计入总量。
- 支持直接生成英文帖、正文不附来源链接；核实后的来源保留在后台。新闻自动发布目前只处理文字，未接入自动配图和视频。

## 独立列表和任务记录

- 自动化任务配置、关系名单、热点列表分别提供侧边栏入口。
- 热点列表支持渠道与执行状态组合筛选，先过滤后分页，每页20条，切换条件回到第一页。按新闻发布时间倒序，热榜缺少发布时间时按采集时间排序，不伪造日期。
- 发布状态包含待处理、处理中、已发 X、跳过、失败和待核对。历史已发内容关联原 X 链接；只有收到有效发布回执才标记成功。
- 关系名单保留关注、粉丝、待回关、未回关分类、搜索和分页同步。勾选后可跳转创建暂停的回关或取关任务。
- 任务记录提供分页、详细执行日志、进度、耗时和模型用量；后台轮询保留列表及详情状态。

## 自动化和浏览器执行

- 区分 For You 评论与通知回复。通知采集仅处理对当前账号的真实回复，排除点赞、关注卡片、单纯提及、自发消息及不完整内容。
- 通知回复支持25秒间隔。任务生成或发送耗时较长时顺延，不并行追赶积压；遇到频率限制时暂停。
- 发送前校验账号、原帖、正文及输入框焦点，并核对 X 请求和发布回执。草稿与不确定结果保留供核对，不自动重发。
- 清理可确认已结束且无草稿的自动化临时页，保留当前页、绑定页和不确定发送页。

## 后台与安装

- 前端迁移到 Vue 3、Soybean Admin 和 Naive UI，复用布局、导航、主题与组件，适配手机和插件管理页面。
- 提供 Docker Compose、源码本地构建及 Skill 安装/升级引导；本地模型默认不下载安装，Codex CLI 生成需要用户配置并登录。
- 更新代码后，Docker 用户需重新构建镜像并重建容器，已有持久化目录继续保留；本次代码提交不代表已发布新镜像或桌面安装包。

热点与浏览器数据采集、发文执行的依赖及字段说明见 [新闻源](NEWS-SOURCES.md)、[Docker 部署](DOCKER.md) 和 [本机后台服务](LOCAL-BACKEND-SERVICE.md)。
